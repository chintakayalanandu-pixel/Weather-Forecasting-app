# 🌤️ Weather Dashboard

A responsive weather dashboard built with **Python (Flask)** and **OpenWeatherMap API**. It shows current weather, hourly forecast, 5-day forecast with an interactive chart, search history, and auto-detect location.

## 🚀 Live Demo

[View Live App](https://weather-forecasting-app-mmb3.onrender.com)

## ✨ Features

- 🌡️ Current weather (temperature, feels like, humidity, wind, pressure)
- ⏰ Hourly forecast for next 24 hours
- 📅 5-day forecast cards
- 📈 Interactive temperature chart (Chart.js)
- 🔍 Search history (saved in browser localStorage)
- 📍 Auto-detect location using browser geolocation
- 🌙 Modern dark glassmorphism UI

## 🛠️ Tech Stack

- **Backend:** Python, Flask, Requests
- **Frontend:** HTML, CSS, JavaScript, Chart.js
- **API:** OpenWeatherMap (free tier)
- **Deployment:** Render.com
